# 安装

## 环境要求

- Vue `^3.5`
- Element Plus `^2.3`

## 使用包管理器

```bash
# pnpm
pnpm add cjx-zdy-ui element-plus @element-plus/icons-vue

# npm
npm i cjx-zdy-ui element-plus @element-plus/icons-vue

# yarn
yarn add cjx-zdy-ui element-plus @element-plus/icons-vue
```

组件库以 Element Plus 为 peer 依赖，请确保项目中已安装。
